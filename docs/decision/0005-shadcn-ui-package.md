# 0005: Shared shadcn/ui Package

**Status:** Accepted
**Date:** 2026-09-29
**Supersedes:** None

## Context

Both frontend applications need a consistent UI foundation and should share component source rather than duplicate primitives.

## Decision

Keep shadcn/ui components and theme in `packages/ui`, and consume them through the `@ultrasakti/ui` workspace package. The initial package contains the official component set generated by the shadcn CLI.

## Consequences

- Shared UI imports use `@ultrasakti/ui/...`.
- Component source remains editable in this repository.
- App-level feature components stay in their app's `src/modules/`.
