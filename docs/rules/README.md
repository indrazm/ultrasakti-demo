# Repository Rules

These rules guide agents and contributors working in this repository. Read the rule that applies to the change, along with [architecture-convention.md](../architecture-convention.md) and any relevant records in [decision/](../decision/README.md).

- [API contract](./api-contract.md): request validation and API response conventions.
- [Backend](./backend.md): Hono modules and backend layering.
- [Database](./database.md): Prisma, migrations, PostgreSQL, and Redis.
- [Frontend](./frontend.md): routes, modules, data fetching, and UI.
- [Monorepo](./monorepo.md): workspace boundaries and package imports.
- [Testing](./testing.md): unit tests and browser end-to-end tests.
- [Tooling](./tooling.md): environment variables, linting, and formatting.
